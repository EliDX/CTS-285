# M4 Investigation Brief

## Product Slice
US-04 — Multi-platform compatibility.

## Trace to Product Work
The criterion that states that if a user wants to access the program, they can do so from any device capable of using the application.

## Initial Design Question
**Question type:** Readiness

What platforms specifically is the Data Man application being developed for currently, and how many different devices do we need to consider?

## Why This Question Matters
Not knowing what devices this application needs to work on best could cause a lot of issues. For example, if it is optimized mainly for school chromebooks that could become an issue if the layout ends up not working well for devices like tablets or phones.

## Planned Evidence
- Dependency check
- Open-question / uncertainty list

## Why This Evidence Is a Reasonable Starting Point
Knowing what cross-platform compatibility depends on would be useful to know where we even need to start when it comes to building the program itself, which will then help us adapt it to different platforms (once we know what platforms we need to adapt it to.

Putting all of our open questions into a list would also help when it comes to knowing what information we need to find out.
